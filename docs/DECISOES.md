# Decisões de desenvolvimento

## 14/10/2026 — entregas locais e identidade

- Priorizar instaladores e entregas locais para teste.
- Não atualizar nem publicar GitHub a cada ajuste. Enviar quando o usuário pedir ou quando for necessário ao processo, por exemplo para compilar o plugin nativo; informar qual operação foi feita.
- Apresentar o produto como CasterDesk. A base da interface deixa de ser foco da comunicação e do relatório atual.
- Preservar identificadores, caminhos de atualização e nomes de dependências necessários à compatibilidade. Não migrar para WPF.
- Mudanças visuais seguem as referências recentes do usuário. Central de imagens fica para discussão posterior; composições atuais preservadas.
