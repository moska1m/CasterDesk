# Histórico recuperado das betas

## Recuperação de 14/10/2026

O histórico local posterior à release 0.2.0-beta.0.3 foi preservado e é continuação do remoto. A atualização dos fontes 0.3.0-beta.0.8 acrescenta a marca e as correções recentes; não substitui ou reescreve commits anteriores.

Instaladores preservados de 0.2.0-beta.0.4 até 0.2.0-beta.0.8, 0.3.0-beta.0.1 até 0.3.0-beta.0.3 e 0.3.0-beta.0.7 são arquivos históricos. Nem todos têm um snapshot exato separado de fontes. A release de arquivo identifica isso explicitamente: os arquivos automáticos de código gerados pelo GitHub para o arquivo histórico não representam cada instalador individual.

As versões 0.3.0-beta.0.4, 0.3.0-beta.0.5 e 0.3.0-beta.0.6 possuem commits locais próprios, mantidos. A 0.3.0-beta.0.8 passa a ter seu snapshot atualizado e instalador com o nome CasterDesk. As betas continuam pré-releases; geração/teste automatizado do pacote não equivale a certificar instalação em outro PC.

## Arquivo anterior

As releases 0.1.0-beta.1 e beta.2 já estavam no GitHub. Os instaladores originais das betas 3 a 8 foram preservados localmente e arquivados juntos na release `archive-0.1.0-beta.3-beta.8`, com hashes SHA256 e as mudanças descritas no CHANGELOG.

Não havia commits separados para essas seis versões intermediárias. O snapshot 0.2.0-beta.0.1 consolida as alterações acumuladas; ele não deve ser interpretado como código exato de cada beta anterior. Os arquivos de código-fonte automáticos da release de arquivo correspondem a esse snapshot consolidado, e não aos instaladores antigos. Não foram fabricados commits retroativos.

A partir de 0.2.0-beta.0.1, cada versão tem seu snapshot e tag próprios; 0.2.0-beta.0.2 registra separadamente a reversão da fonte Scout.
