# Histórico recuperado das betas

As releases 0.1.0-beta.1 e beta.2 já estavam no GitHub. Os instaladores originais das betas 3 a 8 foram preservados localmente e arquivados juntos na release `archive-0.1.0-beta.3-beta.8`, com hashes SHA256 e as mudanças descritas no CHANGELOG.

Não havia commits separados para essas seis versões intermediárias. O snapshot 0.2.0-beta.0.1 consolida as alterações acumuladas; ele não deve ser interpretado como código exato de cada beta anterior. Os arquivos de código-fonte automáticos da release de arquivo correspondem a esse snapshot consolidado, e não aos instaladores antigos. Não foram fabricados commits retroativos.

A partir de 0.2.0-beta.0.1, cada versão tem seu snapshot e tag próprios; 0.2.0-beta.0.2 registra separadamente a reversão da fonte Scout.
